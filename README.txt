LA SAGRADA — Página web

Estructura:
- index.html: estructura de la página
- css/estilos.css: estilos y diseño
- js/script.js: comportamiento del formulario

Cómo abrir:
1. Extrae la carpeta del ZIP.
2. Abre la carpeta LaSagrada en Visual Studio Code.
3. Abre index.html.
4. Opcional: instala la extensión Live Server y usa "Open with Live Server".

Nota:
El formulario genera un resumen de la solicitud en la página, pero no envía pedidos
automáticamente al negocio. Para recibir pedidos reales hay que conectarlo a WhatsApp
o a un servicio/backend.
